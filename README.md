## 📝 Descripción
Aplicativo web para la gestión de tareas en el que se implementa consultas API.

## 🚀 Instalación
```bash
# Pasos necesarios para instalar el proyecto
npm install
npm install axios
npm install json-server@0.17.4 --save-dev

# Pasos para correr el servicio de las APIs.
npx json-server --watch db.json --port 3000

# Pasos para correr el servidor del FrontEnd.
ionic serve
```
